1.2.0-beta — lighter and sturdier under the hood

The mod's folder is now Palished: delete the old PKRepairKeys folder and its line in the loader's mods list before installing.
Timers now use the loader's game-thread functions instead of the async ones, which could drop a callback and leave R, Ctrl+R or the durability bar stuck until restart. The loader must provide ExecuteInGameThreadWithDelay and LoopInGameThreadWithDelay.
R and Ctrl+R are lighter: once no repair window is left, pressing them stops doing any work.
The durability bar is lighter too: it writes to the HUD only when its value changes.
The durability bar follows the game's own gauge: red below 20%, with no orange step.
Log lines are now tagged [Palished].
The hot-reload note is corrected: UE4SS hot reload uses Ctrl+R by default, so set EnableHotReloadSystem = 0 in UE4SS-settings.ini, or change HotReloadKey.

We’d love to hear which details make a difference for you! Leave a comment, share your experience, or report a bug so we can investigate and improve Palished together: https://github.com/PikouGame/Palished/issues

1.1.2-alpha — small details, smoother everyday play

Align Accessory and Food slots with Weapon, keep section spacing consistent, and align the bottom of Sphere Module with the last accessory row.
Show Palworld’s native fist icon and localized Unarmed label in the main HUD when using bare hands. Weapon icons and durability return when you equip a weapon.
R / Ctrl+R repairs, normal repair costs and the Repair All confirmation remain unchanged. Client only; requires UE4SS.
Replace your existing folder; do not install a second copy.
