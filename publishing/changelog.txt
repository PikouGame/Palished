Next version (draft)

The mod's folder is now Palished: delete the old PKRepairKeys folder and its line in the loader's mods list before installing.
Timers now run on the game thread, so a lost callback no longer leaves R, Ctrl+R or the durability bar stuck until restart. The loader must provide ExecuteInGameThreadWithDelay and LoopInGameThreadWithDelay.
R and Ctrl+R are lighter: while no repair window exists, pressing them does nothing at all.
The hot-reload note is corrected: UE4SS hot reload uses Ctrl+R by default, so set EnableHotReloadSystem = 0 in UE4SS-settings.ini, or change HotReloadKey.

1.1.2-alpha — small details, smoother everyday play

Align Accessory and Food slots with Weapon, keep section spacing consistent, and align the bottom of Sphere Module with the last accessory row.

R / Ctrl+R repairs, normal repair costs and the Repair All confirmation remain unchanged. Client only; requires UE4SS.
Replace your existing folder; do not install a second copy.
