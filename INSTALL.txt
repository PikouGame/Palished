Palished 1.2.0-beta — UI enhancements for Palworld

R: selected-item repair. Ctrl+R: normal Repair All confirmation.
Only active at a repair bench; normal costs and disabled-button rules apply.
Equipped-tool durability appears as a compact HUD bar and percentage.
The unarmed HUD uses the native fist and localized name, without durability/ammo.
Equipment slot alignment follows the native Weapon and Head groups.

CLIENT ONLY. Compatible UE4SS for Palworld is required, not bundled.
The loader must provide ExecuteInGameThreadWithDelay and
LoopInGameThreadWithDelay (available in the tested Palworld fork 2281fa31);
otherwise Palished stops at load with a message in the log.
Close Palworld; extract Palished into your existing UE4SS Mods directory.
Keep enabled.txt. If using a mods list, enable Palished without replacing
other entries. Do not install duplicate UE4SS loaders or duplicate mod copies.
Manual loader path: Pal/Binaries/Win64/ue4ss/Mods/Palished
Workshop loader path: Mods/NativeMods/UE4SS/Mods/Palished
UE4SS hot reload uses Ctrl+R by default. Set EnableHotReloadSystem = 0 in
UE4SS-settings.ini, or change HotReloadKey. Restart Palworld after installing.
No server install needed.
Upgrading from 1.1.2 or earlier: delete the old PKRepairKeys folder and its
line in the loader's mods list first.

Tested: Palworld 1.0.5.102999, UE4SS 2281fa31, Windows executable via Wine/Proton.
On this release the author confirmed R and Ctrl+R in game; the durability
display was seen in that session's captures. Other versions, native Windows
OS, controller bindings and HUD-mod conflicts remain unverified.

Uninstall: close the game; remove only Palished and its loader-list entry.
No direct inventory, durability, costs or save edits are performed.
